# Agent Instructions for `cel-cpp`

This file provides guidance for AI agents working with the `cel-cpp` repository.
See [CONTRIBUTING.md](CONTRIBUTING.md) for general contribution guidelines and
[SECURITY.md](SECURITY.md) for the full threat model and security policy.

## Security and Vulnerability Reporting

Before reporting, triaging, or proposing fixes for security-related issues, read
[SECURITY.md](SECURITY.md) to align with `cel-cpp`'s threat model, security
boundaries, and defensive limit expectations.

**Do not report security vulnerabilities in public GitHub issues or pull
requests.** Instead:

*   Report security vulnerabilities via
    [Google's official vulnerability disclosure channel](https://bughunters.google.com/report).
*   For security-sensitive reports that do not meet the criteria or bar for the
    Google Vulnerability Reward Program (VRP), report them privately by opening
    a
    [draft GitHub Security Advisory](https://github.com/cel-expr/cel-cpp/security/advisories/new).
*   For issues that fall under **Outside of Threat Model (Best-Effort
    Hardened)** in [SECURITY.md](SECURITY.md), open a
    [public GitHub issue](https://github.com/cel-expr/cel-cpp/issues) instead.
